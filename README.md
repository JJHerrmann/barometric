# Barometer.Rook.Works

A barometric pressure dashboard for tracking atmospheric patterns related to migraine risk.

This project visualizes pressure trends, deltas, and rates using ICAO weather stations.
It is designed for people who notice migraines correlating with barometric changes.

⚠️ This tool is NOT medical advice.
It does not diagnose, treat, or prevent migraines.
It exists to help users observe patterns.

## Monetization
- Public, ad-supported access
- Optional freemium upgrades planned (alerts, history, exports)

## Tech
