Project name:
barometric-rook-works

Primary domain:

---

## Project Goal

Turn a single-file React dashboard (supplied separately in ChatGPT canvas)
into a production, SEO-indexable Next.js website.

The site must:
- Be publicly accessible (no login required for v1)
- Monetize via ads initially, with optional freemium upgrades later
- Target users tracking migraine risk related to barometric pressure changes
- Avoid medical claims (tracking and pattern recognition only)

---

## What Is Already Implemented (DO NOT REWRITE)

The dashboard component provided in the canvas already includes:

- Complete React component logic
- Future Dusk aesthetic:
  - indigo / violet / near-black gradients
  - glassmorphism panels (no fluffy gradients)
  - hex grid background overlay
- Dual-unit formatting everywhere:
  - Pressure: inHg (hPa)
  - Temperature: F (C)
- Station selector:
  - Preset ICAO stations
  - Custom ICAO input
  - “Unknown station” error strip with fallback mock data
- Mock time-series data generator
- Migraine risk scoring (delta + rate based)
- Dev-only console.assert tests

This file is the **single source of truth** for the dashboard.
It must be copied verbatim into the repo.
